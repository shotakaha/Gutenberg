## Changelog

This is a maintenance fork of [BafS/Gutenberg](https://github.com/BafS/Gutenberg).
The fork point is upstream **v0.7.0** (commit `cec4afe`, 2023-02-22), the last
release published by the original author. For the history up to and including
v0.7.0, see the [upstream releases](https://github.com/BafS/Gutenberg/releases).

From v0.7.0 onward this file is generated by
[release-please](https://github.com/googleapis/release-please) from
[Conventional Commits](https://www.conventionalcommits.org/); do not edit it by
hand.

## Unreleased (since the fork point)

Groundwork laid before release automation was in place — these land in the first
tagged release cut from this fork:

- **build:** replace the abandoned `sass-lint` with `stylelint` +
  `stylelint-config-standard-scss`, tuned so current sources pass unchanged
  (see `.stylelintrc.js`); `npm test` now runs it.
- **ci:** GitHub Actions running lint + build on Node 20/22/24, plus a check
  that `dist/` stays in sync with `scss/`.
- **build:** raise `engines.node` to `>=20.19` (stylelint 17 minimum); migrate
  `package-lock.json` to lockfile v3.
- **build:** commit tooling — commitlint + husky + lint-staged enforce
  Conventional Commits and lint staged SCSS.
- **chore:** point `repository` / `bugs` / `homepage` at the fork; drop the dead
  Travis, Code Climate, and `sass-lint` config files.

Known: `npm audit` warnings all originate in the `gulp` 4 devDependency tree
(build-time only, nothing ships in `dist/`); clearing them needs a build-tool
change, deferred to its own commit.
